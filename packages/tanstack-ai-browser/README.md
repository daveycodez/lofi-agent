# @daveycodez/tanstack-ai-browser

[TanStack AI](https://tanstack.com/ai) adapters for language models that run in the browser. The first runs [Transformers.js](https://huggingface.co/docs/transformers.js) models on WebGPU in a Web Worker, tuned for Safari on iPhone.

**Status:** in development, not published yet. See the [repository README](../../README.md).
